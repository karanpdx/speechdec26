# Plan 1: Implement ContrastiveLoss

## Objective
Implement the `ContrastiveLoss` class in `src/training/losses.py` so all `TestContrastiveLoss` tests pass.

## Context
The stub in `src/training/losses.py` has `raise NotImplementedError` in both `__init__` and `forward`. The class must:
- Store log-temperature as `nn.Parameter` when `learnable_temp=True`, or as a plain float when `False`
- L2-normalize both inputs internally via `F.normalize(..., dim=-1)`
- Clamp temperature to `[log(0.01), log(100)]` = `[-4.605, 4.605]` on every forward pass
- Compute symmetric cross-entropy: logits = exp(clamp(log_temp)) * (neural_norm @ text_norm.T), then average CE in both directions
- Raise `ValueError` if `neural_emb.shape[0] == 1`

Key test constraints from `tests/test_losses.py`:
- `learnable_temp=True` → exactly 1 `nn.Parameter`
- `learnable_temp=False` → 0 parameters
- Temperature clamping must prevent NaN even when parameter is set to 1000.0
- Gradients must flow through both `neural_emb` and `text_emb`
- Loss is scalar (`shape == ()`)

## Tasks

### Task 1: Implement ContrastiveLoss.__init__
**Action:** Replace the `raise NotImplementedError` in `ContrastiveLoss.__init__` with working initialization.
**File:** `src/training/losses.py`
**Details:**
- Import `math` at the top of the file (needed for `math.log`)
- When `learnable_temp=True`: `self.log_temp = nn.Parameter(torch.tensor(math.log(temperature_init)))`
- When `learnable_temp=False`: `self.register_buffer('log_temp', torch.tensor(math.log(temperature_init)))` — or store as plain float. Using `register_buffer` is cleaner for device movement, but note that buffers don't appear in `parameters()`, satisfying the "0 params" test. Either approach works; use `register_buffer` for device safety.

### Task 2: Implement ContrastiveLoss.forward
**Action:** Replace the `raise NotImplementedError` in `ContrastiveLoss.forward` with the symmetric contrastive loss computation.
**File:** `src/training/losses.py`
**Details:**
1. Check `if neural_emb.shape[0] == 1: raise ValueError("Contrastive loss is undefined for batch size 1")`
2. L2-normalize: `n = F.normalize(neural_emb, dim=-1)`, `t = F.normalize(text_emb, dim=-1)`
3. Clamp: `temp = torch.clamp(self.log_temp, min=math.log(0.01), max=math.log(100)).exp()`
4. Logits: `logits = temp * (n @ t.T)`  — shape `(batch, batch)`
5. Labels: `labels = torch.arange(batch, device=neural_emb.device)`
6. Loss: `(F.cross_entropy(logits, labels) + F.cross_entropy(logits.T, labels)) / 2`
7. Return the scalar loss
