# Plan 2: Implement CrossModalAlignmentLoss

## Objective
Implement the `CrossModalAlignmentLoss` class in `src/training/losses.py` so all `TestCrossModalAlignmentLoss` tests pass.

## Context
`CrossModalAlignmentLoss` wraps `ContrastiveLoss` (Plan 1 must be complete — `ContrastiveLoss` must be working before this plan executes). The class filters both embeddings to only the rows where `shared_label_mask` is `True`, then runs contrastive loss on that subset.

Key test constraints:
- Mask with 0 True entries → return `torch.tensor(0.0, requires_grad=True)`, NOT a crash
- Mask with exactly 1 True entry → same zero return (< 2 matches)
- Full mask → positive scalar loss, gradients flow through `emb_a`
- The zero tensor must have `requires_grad=True` (tested explicitly)

The `__init__` currently has `raise NotImplementedError` — it must instantiate a temperature parameter and an internal `ContrastiveLoss` instance (or replicate the logic).

**Action:** Replace `raise NotImplementedError` in `CrossModalAlignmentLoss.forward`.
**File:** `src/training/losses.py`
**Details:**
