  <behavior>
    - For each index i: check whether batch[i]["label"] appears in any batch[j] where j != i and batch[j]["modality"] != batch[i]["modality"]
    - Returns torch.BoolTensor of length len(batch)
    - Edge cases:
        Empty batch (len == 0): return torch.zeros(0, dtype=torch.bool)
        All same modality: every entry is False
        Label appears in two samples of same modality only: both are False
        Label appears in samples of two different modalities: all such samples are True
    - Must be O(batch_size * unique_labels) or better — do not use O(batch_size^2) nested loop

    Efficient approach:
      1. Build label_to_modalities: dict[str, set[str]] — for each label, what modalities have it
      2. mask[i] = True iff len(label_to_modalities[batch[i]["label"]]) >= 2
         (label appears in at least 2 distinct modalities)
  </behavior>
  <action>
    Replace the `build_shared_label_mask` body (currently `raise NotImplementedError`).

    Implementation:
      if not batch:
          return torch.zeros(0, dtype=torch.bool)

      # Build mapping from label -> set of modalities that have it
      label_to_modalities: dict[str, set] = {}
      for item in batch:
          label_to_modalities.setdefault(item["label"], set()).add(item["modality"])

      # A sample is a cross-modal match if its label appears in >= 2 distinct modalities
      mask = torch.tensor(
          [len(label_to_modalities[item["label"]]) >= 2 for item in batch],
          dtype=torch.bool,
      )
      return mask
  </action>
